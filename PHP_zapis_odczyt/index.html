🎯 Czego się nauczysz?

W tym tutorialu poznasz podstawy pracy z bazami danych MySQL i językiem PHP. Nauczysz się jak tworzyć proste aplikacje internetowe, które mogą:

  • ✅ Zbierać dane z formularzy HTML
  • ✅ Zapisywać dane do bazy MySQL
  • ✅ Odczytywać dane z bazy
  • ✅ Wyświetlać dane na różne sposoby
  • ✅ Filtrować i wyszukiwać informacje

⚠️ Czego potrzebujesz?

Przed rozpoczęciem upewnij się, że masz:

  1. Serwer lokalny - XAMPP, WAMP lub podobny (z Apache + MySQL)
  2. Edytor kodu - Notepad++, Visual Studio Code lub inny
  3. Przeglądarkę - Chrome, Firefox lub inną
  4. Podstawową wiedzę HTML - formularze, tagi, atrybuty

⚙️ Instalacja i Konfiguracja

1 Zainstaluj XAMPP

Pobierz XAMPP z apachefriends.org i zainstaluj na swoim komputerze

2 Uruchom serwery

Otwórz XAMPP Control Panel i uruchom Apache oraz MySQL

3 Skopiuj pliki tutoriala

Skopiuj cały folder PHP_zapis_odczyt do folderu htdocs w katalogu XAMPP (np. C:\xampp\htdocs\)

4 Utwórz bazę danych

Otwórz przeglądarkę i wejdź na http://localhost/phpmyadmin

Kliknij zakładkę "Import" i zaimportuj plik create_database.sql

5 Skonfiguruj połączenie

Otwórz plik db_config.php i sprawdź czy dane logowania są poprawne:

$db_host = "localhost"; $db_user = "root"; $db_password = ""; // Zwykle puste $db_name = "szkola_db";
6 Gotowe!

Otwórz przeglądarkę i wejdź na:

http://localhost/PHP_zapis_odczyt/

💡 Wskazówki dla uczniów

✏️ Jak najlepiej się uczyć?

  1. 📖 Czytaj kod uważnie - każda linijka ma komentarz wyjaśniający
  2. ⌨️ Przepisuj kod ręcznie - nie kopiuj-wklej, pisz sam!
  3. 🔬 Eksperymentuj - zmieniaj kod i zobacz co się stanie
  4. ❓ Zadawaj pytania - nie rozumiesz? Pytaj nauczyciela!
  5. 🐛 Analizuj błędy - błędy to najlepszy sposób nauki
  6. 🔄 Powtarzaj - przejdź tutorial kilka razy

🐛 Najczęstsze błędy i ich rozwiązania

  • ❌ "Cannot connect to database"
    → Sprawdź czy MySQL jest uruchomiony w XAMPP
  • ❌ "Table doesn't exist"
    → Zaimportuj plik create_database.sql w phpMyAdmin
  • ❌ "Undefined index"
    → Użyj isset() przed $_GET lub $_POST
  • ❌ Polskie znaki wyświetlają się źle
    → Sprawdź czy masz <meta charset="UTF-8"> i mysqli_set_charset($conn, "utf8mb4")
  • ❌ Strona jest biała (pusty ekran)
    → Włącz wyświetlanie błędów w PHP lub sprawdź logi błędów Apache
